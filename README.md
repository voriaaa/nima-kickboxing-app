# اپ باشگاه کیک‌بوکس نیما افشار

اپ اندروید باشگاه، ساخته‌شده با Flutter. فقط استفاده‌ی داخلی (بدون انتشار در بازار/مایکت).
تم مشکی و آبی، فونت وزیرمتن و Bebas Neue، اعداد انگلیسی.

## بخش‌ها

یک ورودی مشترک برای همه؛ ابزارهای مربی پشت رمز در تب «باشگاه».

- **خانه:** معرفی باشگاه، کمبوی روز (متحرک)، برنامه‌ی امروز، آخرین اطلاعیه، دسترسی سریع
- **آموزش:** ۱۸ حرکت (گارد، مشت‌ها، لگدها، زانو، دفاع) با فیگور وکتوری متحرک، فریم‌های مرحله‌به‌مرحله، فلش جهت ضربه، توضیح، نکته‌ها و اشتباهات رایج. سرعت قابل تنظیم (0.25x تا 1x)
- **کمبو:** ۱۸ ترکیب در سه سطح + سازنده‌ی کمبوی تصادفی؛ اجرای متحرک کمبو با نمایش حرکت فعلی
- **تایمر:** راند، استراحت، آماده‌سازی، حالت «کمبو خوان» برای شدوبوکس
- **باشگاه:** برنامه‌ی هفتگی و اطلاعیه‌ها برای همه؛ «پنل مربی» با رمز (شاگردان، حضور و غیاب، شهریه، ویرایش برنامه و اطلاعیه)
- **رزرو و مشاوره:** اینستاگرام، تلگرام، تماس و پیامک با استاد

## محدودیت فعلی

داده‌ها فعلاً **فقط روی همان گوشی** ذخیره می‌شوند؛ چیزی که مربی ثبت می‌کند روی گوشی شاگردها دیده نمی‌شود
تا بک‌اند مشترک (PocketBase) وصل شود. رمز پنل مربی یک قفل ساده‌ی محلی است، نه امنیت واقعی.

## ساخت APK

با هر پوش، GitHub Actions فایل APK می‌سازد. پوش روی `main` یک Release با فایل
`nima-kickboxing.apk` منتشر می‌کند. پوش روی شاخه‌های دیگر فقط تست و ساخت است و
گردش کار Screenshots تصویر صفحه‌ها را در شاخه‌ی `screens` می‌گذارد.

## فیگورهای حرکات

ژست‌ها در `tool/poses.py` تعریف می‌شوند (زاویه‌ی مفصل‌ها در نمای کناری).
بعد از تغییر:

```bash
python3 tool/poses.py preview /tmp/preview   # تصویر همه‌ی ژست‌ها برای بررسی
python3 tool/poses.py dart                   # بازسازی lib/moves/pose_data.g.dart
python3 tool/figure_preview.py /tmp/f.png jab rhigh   # پیش‌نمایش ظاهر فیگور (pip install skia-python)
python3 tool/make_icon.py                    # آیکن اپ (مشت با باند بوکس)
```

ظاهر فیگور (بدن، شورت، دستکش، نور لبه) در `lib/moves/fighter.dart` و هم‌زمان در
`tool/figure_preview.py` تعریف شده؛ هر تغییری باید در هر دو اعمال شود.

## تست روی گوشی (شبیه‌ساز)

گردش کار «Device test» با هر پوش، APK نهایی را روی شبیه‌ساز اندروید نصب و اجرا می‌کند،
از صفحه‌ها عکس می‌گیرد و لاگ خطا را در شاخه‌ی `device` می‌گذارد.

## ساختار

```
lib/
  main.dart, theme.dart, util.dart, club_info.dart, models.dart
  data/app_store.dart        ذخیره‌ی داده (محلی)
  moves/fighter.dart         موتور فیگور متحرک
  moves/pose_data.g.dart     ژست‌ها (تولیدشده)
  moves/moves.dart           متن آموزش حرکات و کمبوها
  ui/                        صفحه‌ها
tool/                        ابزار ژست، آیکن و اسکرین‌شات
```

فونت‌ها با مجوز OFL در `assets/fonts` هستند.
