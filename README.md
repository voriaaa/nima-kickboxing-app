# اپ باشگاه کیک‌بوکس نیما افشار

اپ اندروید برای مربی و شاگردهای یک باشگاه کوچک، ساخته‌شده با Flutter.
فقط استفاده‌ی داخلی (بدون انتشار در بازار/مایکت).

- اینستاگرام: instagram.com/nimaafshar_kickboxing_
- تلگرام: @nimaafshar12

## امکانات نسخه‌ی اول

**مربی** (ورود با رمز ۴ تا ۸ رقمی)
- ثبت و ویرایش شاگردها: تماس، تماس اضطراری، سطح، وزن، شهریه، یادداشت خصوصی
- حضور و غیاب روزانه با یک تپ، با تاریخ شمسی
- شهریه‌ی ماهانه: ثبت پرداخت، وضعیت (پرداخت‌شده / بخشی / پرداخت‌نشده)، جمع انتظار و دریافتی
- برنامه‌ی هفتگی تمرین و اطلاعیه

**شاگرد** (انتخاب نام خود)
- دیدن برنامه‌ی تمرین و اطلاعیه‌ها
- دیدن حضور این ماه و وضعیت شهریه‌ی خودش

**هر دو:** تایمر راند (آماده‌سازی، راند، استراحت) که بدون اینترنت کار می‌کند و صفحه را روشن نگه می‌دارد.

## محدودیت فعلی (مهم)

داده‌ها فعلاً **فقط روی همان گوشی** ذخیره می‌شوند. یعنی چیزی که مربی روی گوشی خودش ثبت می‌کند
هنوز روی گوشی شاگردها دیده نمی‌شود. مرحله‌ی بعدی اتصال به بک‌اند مشترک است
(کلاس `AppStore` در `lib/data/app_store.dart` برای همین جایگزین‌شدنی نوشته شده).
رمز مربی هم فعلاً فقط یک قفل ساده‌ی محلی است، نه امنیت واقعی.

## ساخت APK با GitHub Actions

1. پروژه را در یک مخزن گیت‌هاب پوش کن (شاخه‌ی `main`).
2. در تب **Actions** گردش کار «Build APK» خودکار اجرا می‌شود (یا دستی با Run workflow).
3. بعد از چند دقیقه فایل `nima-kickboxing.apk` در بخش **Releases** مخزن و در Artifacts همان اجرا آماده است.
4. فایل را برای شاگردها بفرست و در گوشی نصب کنند (اجازه‌ی نصب از منبع ناشناس لازم است).

اگر مخزن خصوصی باشد، دانلود از Releases فقط برای کسانی ممکن است که به مخزن دسترسی دارند.
برای توزیع بین شاگردها، فایل APK را از آنجا دانلود کن و در تلگرام/واتساپ بفرست.

## اجرا روی کامپیوتر (اختیاری)

```bash
flutter create . --platforms=android --org ir.nimaafshar --project-name nima_kickboxing
flutter pub get
flutter run
```

## ساختار پروژه

```
lib/
  main.dart            شروع برنامه، تم، زبان فارسی و راست‌به‌چپ
  models.dart          شاگرد، پرداخت، برنامه‌ی تمرین، اطلاعیه
  util.dart            تاریخ شمسی، ارقام فارسی، قالب مبلغ
  data/app_store.dart  ذخیره‌ی داده (محلی)
  ui/                  صفحه‌ها (مربی، شاگرد، تایمر)
```

## قدم‌های بعدی

1. بک‌اند مشترک برای همگام‌سازی گوشی مربی و شاگردها (ورود با شماره‌ی موبایل)
2. اعلان (نوتیفیکیشن) برای اطلاعیه و یادآوری شهریه
3. آیکن و نام نهایی اپ، فونت وزیرمتن، صدای زنگ واقعی برای تایمر
4. ثبت رکورد و پیشرفت شاگردها، مسابقات
